# Introduction

Oasi UI is a modern Vue 3 component library with:

- **Visual language** inspired by HeroUI v3 (MIT License)
- **Tailwind CSS v4** as the styling engine
- **CVA** (class-variance-authority) for type-safe variants
- **OKLCH color space** for perceptual uniformity
- **SSR-safe** from day one
- **Tree-shakeable** — pay only for what you import
- **70+ components** and growing

## Bundle size

Tree-shaking is first-class. Typical footprints on top of Vue:

| Usage | Gzipped |
|---|---|
| Only `OButton` | ~10 kB |
| 10 typical components (Button, Input, Card, Tooltip, Avatar, Checkbox…) | ~71 kB |
| Entire library (`import *`) | ~156 kB |

Heavy components (`OChart`, `OConfetti`, `OCommandPalette`, `OCalendar`) are stripped entirely if you don't import them.
