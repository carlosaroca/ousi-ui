# Installation

## Requirements

- Vue 3.5+
- Tailwind CSS v4
- Node.js 18+

## Install

```bash
pnpm add @ousi-ui/vue @ousi-ui/theme
```

## Import Styles

Add to your main CSS file:

```css
@import "tailwindcss";
@import "@ousi-ui/theme";
@source "../node_modules/@ousi-ui/vue/src/**/*.{ts,vue}";
```

## Use Components

```vue
<script setup>
import { OButton } from '@ousi-ui/vue'
</script>

<template>
  <OButton>Click me</OButton>
</template>
```

## Plugin (Optional)

Register all components globally:

```ts
import { createApp } from 'vue'
import { OusiUIPlugin } from '@ousi-ui/vue'

const app = createApp(App)
app.use(OusiUIPlugin)
app.mount('#app')
```
