# Introduction

Ousi UI is a Vue 3 component library built with Tailwind CSS. It provides a set of beautifully designed, accessible, and customizable components.

## Features

- **Vue 3** — Built with Composition API and `<script setup>`
- **Tailwind CSS** — Styled with utility classes and design tokens
- **Themeable** — Multiple built-in themes with full customization support
- **TypeScript** — Full type safety with exported prop types
- **Accessible** — WAI-ARIA compliant components

## Quick Start

Install Ousi UI in your project:

```bash
pnpm add @ousi-ui/vue @ousi-ui/theme
```

Then import and use components:

```vue
<script setup>
import { OButton } from '@ousi-ui/vue'
</script>

<template>
  <OButton variant="accent">Click me</OButton>
</template>
```
